# AI-Powered Text Classification

A Streamlit web app that predicts POSITIVE or NEGATIVE sentiment using a pretrained Hugging Face model.

## Deploy for free

1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Select **Create app**, choose the repository and `app.py`, then deploy.
4. The first start downloads the pretrained model and may take a few minutes.

Model: `distilbert/distilbert-base-uncased-finetuned-sst-2-english`
